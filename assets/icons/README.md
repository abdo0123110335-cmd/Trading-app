# App icons

This folder is referenced by `pubspec.yaml` (`assets/icons/`) for any
in-app icon assets you add later (e.g. custom indicator glyphs).

The Android **launcher icon** itself is NOT here — it lives under
`android/app/src/main/res/mipmap-*/ic_launcher.png` once you run
`flutter create .` (see the main README's "Project setup" section).
Replace those generated placeholder mipmap files with your own
"Binance Spot Pro" icon, or run a launcher-icon generator such as the
`flutter_launcher_icons` package against a source image you place here.
